# Validation Case Study: UCI Wine Recognition Dataset

This case study validates `shiftcheck` on the **UCI Wine Recognition Dataset** (Forina et al.).
It compares three cultivars of Italian wine using 13 chemical features, probing whether
varietal differences are driven by concentration shifts, correlation restructuring, or both.

See full narrative report: `docs/WINE_VALIDATION_CASE_STUDY.md`
Run: `PYTHONPATH=src python examples/wine_cultivar_shift.py`
